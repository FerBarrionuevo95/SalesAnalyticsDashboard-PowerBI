## The Project

This project focused on transforming a sales dataset into an interactive Power BI dashboard designed to explore sales performance and identify relevant business patterns.

The project involved preparing the data, creating analytical measures and developing visualizations to support a clearer understanding of sales performance.

---

## The Objective

The main objective was to transform raw sales data into a structured and interactive dashboard that could help answer business questions related to:

- Sales performance
- Revenue and costs
- Product and category performance
- Temporal trends
- Units sold
- Key performance indicators

---

## Data Preparation

The dataset was cleaned and prepared before building the dashboard.

The process included:

- Data cleaning and normalization
- Data transformation using Power Query
- Creation of calculated columns
- Creation of analytical measures using DAX
- Calendar table creation
- Preparation of the data model for visualization
